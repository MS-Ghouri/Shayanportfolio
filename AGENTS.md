## Global System Instructions for All Agents

### 1. The Credibility Standard
- **Never invent** qualifications, certifications, metrics, or technologies.
- Categorize all tech into:
  - **Core**: Deep competency, daily use, can defend architectural choices and internals in an interview.
  - **Working Knowledge**: Competent practical application, project experience, understands core concepts.
  - **Currently Learning**: Actively studying, exploring in coursework or experiments.
- If an item cannot be defended in an interview or technical review, do not present it as personal expertise.

### 2. Team Distinction
- Clearly differentiate Shayan's **individual capability** (software development, core logic, architecture) from **collaborative team delivery** (full-scale agency projects where multi-disciplinary specialists contributed).

### 3. Execution Methodology (Baby Steps Only)
- Do not rush.
- Do not dump mass unreviewed code.
- Each agent handles their specific layer, presents outputs, and waits for validation.

### 4. Tech Philosophy
- Pure Semantic HTML5 (`<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`).
- Modern vanilla CSS (custom properties, responsive grid/flexbox, fluid typography).
- Vanilla modern JavaScript (ES modules, zero unnecessary frameworks or bloat).
- WCAG 2.2 Level AA compliance (contrast, keyboard navigation, visible focus rings, reduced-motion support).
